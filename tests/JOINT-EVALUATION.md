# Joint subscription evaluation with an API-equivalent cap

Run the reviewed `scripts/joint_evaluation.py` with isolated Python (`python -I -B -X pycache_prefix=/dev/null`), a controller configuration path and its independently reviewed SHA256. These flags prevent reads from existing bytecode caches as well as new cache writes; source admission also rejects untracked or ignored native import modules. Modes are `dry-admission`, `probe`, and `run`. The exact source/runtime/model/registry/Floor-policy bindings and runnable commands live in the local task c-i command packet. The plugin package does not ship a spending opt-in.

Dry admission requires the presence of `DEMO_CLAUDE_CODE_OAUTH_TOKEN` but never reads its value. It validates source, runtime, Floor policy, canonical ledger recovery/init eligibility, and sandbox availability with zero API calls and no ledger initialization. Run operator commands through `env -u ANTHROPIC_BASE_URL`: desktop sessions may set that variable even to the default URL, and any ambient value remains deliberately refused. Invocation modes require the nonempty owner token, mapped privately in the parent to `CLAUDE_CODE_OAUTH_TOKEN`. The parent official SDK sends this bearer with the frozen OAuth capability; it explicitly disables API-key fallback. The token is never logged, persisted, or passed to a child. Exact account/model availability is proved only by the bounded invocation; OAuth setup tokens need inference scope, so there is no Models API preflight. API keys, subscription login files, Codex and Terra never authorize this controller. Custom auth headers/endpoints and provider-routing/logging overrides are refused.

The child uses macOS Seatbelt deny-default confinement. Only reviewed runtime/plugin inputs are readable; only its fresh scratch is writable. Its network grant is one local broker port protected by a unique session capability. A scratch-only `apiKeyHelper` supplies the child that local broker nonce; this is not a provider credential. No auth environment variable is inherited. The owner OAuth credential, ledger, host home, keychain, other processes, and external/Unix-socket network paths are inaccessible. The broker permits only the exact reviewed Messages route and local Bash/Skill tool definitions, serially; no server tools or helper model substitution. Replay retains real Bash and `pipefail`, with no network grant. Descendants inherit the sandbox. Process groups are killed at completion; even a detached descendant loses its broker capability, and a reused port requires a new capability. A hostile owner/OS or kernel escape is outside this threat model.

The broker uses the official pinned SDK with automatic retries and ambient proxies disabled. It removes prompt caching and reserves the model's entire frozen provider hard context maximum plus 2048 maximum output tokens using frozen standard/global rates. The derivative model registry binds the official context-limit sources for each exact model. A pre-forward model-specific JSON byte ceiling adds defense; bytes are not claimed to be a tokenizer proof. The frozen native beta allowlist excludes unknown, context-expanding, fast, fallback, server-tool and batch capabilities. Caching and context edits are scrubbed or refused. Haiku manual thinking is normalized to a valid 1024-token budget within the same 2048-token output cap; the CLI native default budget cannot be retained when output is capped. Plugin trials have a $1 API-equivalent session stop threshold plus one request's maximum exposure. Floor/judge/probe are single-request sessions with a one-microdollar threshold plus request exposure; the Haiku probe reserves $0.210241. These reservations are deliberately conservative and may stop the aggregate run with unused headroom. The $50 cap is API-equivalent usage, not a subscription invoice. No completion within that cap is promised.

Every API request has a durable intent and provider usage record before its response reaches the child. The ledger recomputes API-equivalent dollars from attributable server token counters at frozen registry rates. Native Claude Code must independently report matching aggregate/model token counters and `total_cost_usd`/model cost; both costs must agree within the per-request microdollar rounding allowance. Native reported cost alone never authorizes settlement. All phases and retries share the single canonical $50 ledger. Timeouts, crashes, missing/malformed usage, mismatched native reports, or corrupt evidence retain the full reservation and halt. A provider 429/rate limit writes a safe terminal `STOPPED_RATE_LIMIT` partial artifact, kills the child process group and stops all phases, including Floor judges. Provider retries are zero; no retry or route fallback follows the limit. Any terminal session failure revokes the broker and kills the child immediately. Upstream HTTP status/transport classification is persisted in `session-stop.json` without SDK error bodies or headers, and `child-stop.json` retains bounded, capability-redacted child stderr and timeout output. The broker returns an explicit non-retryable terminal error rather than mapping every failure to authentication HTTP 403. Reconciliation never infers zero cost from a failed request. A permanent init marker prevents loss of the database from silently creating a fresh budget. There is no reset or automatic repair command. The repaired probe uses `joint-oauth-availability-probe-v2`; changing its identity does not clear an uncertain prior call, a ledger halt or a registry mismatch. The original v1 reservation remains charged until reviewed recovery establishes eligibility.

All trial phases use native Claude Code through the same parent broker so native cost can be cross-checked. Routing captures the first observed Skill and drains exactly one bounded model turn for its final usage report. The joint run preserves 35 sufficiency trials, 50 routing trials, and a fresh unfiltered 153-fact Floor baseline (1530 trials and 306 judges). A completed plugin run that misses scoring thresholds still proceeds to Floor when accounting is safe; joint acceptance remains failed. Financial/execution incompleteness suppresses further work. Offline fixtures and dry admission do not prove account availability, paid acceptance, source-flag adjudication, release, or promotion.
