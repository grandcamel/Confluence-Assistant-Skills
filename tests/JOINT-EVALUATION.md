# Joint paid evaluation

Run the reviewed `scripts/joint_evaluation.py` with isolated Python (`python -I -B -X pycache_prefix=/dev/null`), a controller configuration path and its independently reviewed SHA256. These flags prevent reads from existing bytecode caches as well as new cache writes; source admission also rejects untracked or ignored native import modules. Modes are `dry-admission`, `probe`, and `run`. The exact source/runtime/model/registry/Floor-policy bindings and runnable commands live in the local task c-i command packet. The plugin package does not ship a spending opt-in.

Dry admission validates source, runtime, Floor policy, canonical ledger recovery/init eligibility, and sandbox availability. It makes no API call, reads no provider key, and never initializes a spend ledger. Paid modes additionally require `ANTHROPIC_API_KEY` from the owner environment and exact account/model/context availability via the first-party Models API. Subscription tokens, custom auth headers/endpoints, and provider-routing/logging overrides are refused. An absent key or incompatible runtime stops before spend.

The child uses macOS Seatbelt deny-default confinement. Only reviewed runtime/plugin inputs are readable; only its fresh scratch is writable. Its network grant is one local broker port protected by a unique session capability. Real API credentials, ledger, host home, keychain, other processes, and external/Unix-socket network paths are inaccessible. The broker permits only the exact reviewed Messages route and local Bash/Skill tool definitions, serially; no server tools or helper model substitution. Replay retains real Bash and `pipefail`, with no network grant. Descendants inherit the sandbox. Process groups are killed at completion; even a detached descendant loses its broker capability, and a reused port requires a new capability. A hostile owner/OS or kernel escape is outside this threat model.

The broker uses the official pinned SDK with automatic retries and ambient proxies disabled. It removes prompt caching and reserves the model's entire advertised input window plus 2048 maximum output tokens using frozen standard/global rates. Plugin trials have a $1 session stop threshold plus one request's maximum exposure. Floor/judge/probe are single-request sessions with a one-microdollar threshold plus request exposure; the Haiku probe reserves $0.210241. These reservations are deliberately conservative and may stop the aggregate run with unused headroom. No completion within $50 is promised.

Every API request has a durable intent and provider usage record before its response reaches the child. The ledger recomputes dollars from attributable API counters; Claude Code's reported dollar total is never authoritative. All phases and retries share the single canonical $50 ledger. Timeouts, crashes, missing usage, or corrupt evidence retain reservations and halt. Reconciliation never infers zero cost from a failed request. A permanent init marker prevents loss of the database from silently creating a fresh budget. There is no reset or automatic repair command.

The joint run preserves 35 sufficiency trials, 50 routing trials, and a fresh unfiltered 153-fact Floor baseline (1530 trials and 306 judges). A completed plugin run that misses scoring thresholds still proceeds to Floor when accounting is safe; joint acceptance remains failed. Financial/execution incompleteness suppresses further work. Offline fixtures and dry admission do not prove account availability, paid acceptance, source-flag adjudication, release, or promotion.
